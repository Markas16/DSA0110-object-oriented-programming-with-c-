3. Impact of Removing virtual from total()
===================================================
In complete_billing.cpp, if virtual is removed from Bill::total():
complete_billing.cpp:18:20: error: 'virtual double Bill::total() const = 0' cannot be non-virtual
If replaced by a non-virtual definition 'double total() const { return 0.0; }':
The output changes to:
OP Ravi: 0
IP Meena: 0
Total 0
Because static binding calls Bill::total() directly through Bill* pointer!
